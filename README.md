# 📊 E-Commerce Sales Analytics Dashboard

## 📌 Project Overview
This project focuses on analyzing an E-Commerce Sales dataset using:
- Python 
- MySQL
- Power BI

The goal of this project is to identify business insights related to:
- Sales Performance
- Customer Behavior
- Product Profitability
- Shipping Operations
- Regional Analysis

The project includes:

✔ Data Cleaning  
✔ Exploratory Data Analysis (EDA)  
✔ SQL Business Queries  
✔ Interactive Power BI Dashboard  



# 🛠 Tools & Technologies Used

- Python
- Pandas
- Jupyter Notebook
- MySQL Workbench
- SQL
- Power BI
- GitHub



# 📂 Project Workflow

## 1️⃣ Data Cleaning
Performed data preprocessing using Pandas:
- Removed duplicates
- Handled missing values
- Corrected data types
- Created new calculated columns
- Standardized column names
- Profit Margin calculation



## 2️⃣ Exploratory Data Analysis (EDA)
Analyzed:
- Sales trends
- Category performance
- Customer contribution
- Shipping analysis
- Profitability trends
- Discount impact on profit



## 3️⃣ SQL Analysis
Performed SQL queries using:
- GROUP BY
- Aggregate Functions
- Window Functions
- CTEs
- Ranking Functions

Business insights generated for:
- Top products
- Top customers
- Customer lifetime value
- Profit margin
- Running sales analysis
- Shipping cost analysis



# 📊 Power BI Dashboard Pages

## 📌 Executive Overview
- Total Sales
- Total Profit
- Profit Margin
- Sales Trend
- Sales by Category
- Sales by Region
- Customer Segment Analysis

### Key Insights
- Technology category contributes highest sales.
- Central region generates highest sales and profit.
- High discounts reduce profitability.



## 📌 Customer Analysis
- Top Customers
- Customer Segment Sales
- Customer Distribution by Region
- Monthly Segment Trend

### Key Insights
- Consumer segment generates highest sales.
- Central region has highest customer share.
- Top customers contribute major revenue share.



## 📌 Product Analysis
- Top Products by Sales
- Profit by Sub-category
- Bottom Products
- Discount vs Profit

### Key Insights
- Technology category leads in sales.
- Copiers and Phones are most profitable.
- High discounts negatively impact profit.



## 📌 Shipping & Operations
- Shipping Cost Analysis
- Sales by Ship Mode
- Shipping Cost vs Profit

### Key Insights
- Standard Class is most used shipping mode.
- High shipping cost does not always increase profit.



# 📈 Business Impact
This dashboard helps businesses:
- Track KPI metrics
- Improve profitability
- Optimize shipping strategy
- Identify loss-making products
- Understand customer behavior
- Make data-driven decisions
